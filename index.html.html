01 · Start Here

Welcome to your Privacy USB guide. Read this chapter before restarting your computer.

What is Tails?

Tails is a live operating system designed to help protect privacy. It runs from a USB drive and routes supported internet connections through Tor. It is not a promise of perfect anonymity.

Before you begin

  • Save your work and close open applications.
  • Use a computer compatible with Tails. Hardware and Wi-Fi support can vary.
  • Keep this guide available on another device or in a browser before rebooting.
  • Never use a USB drive whose origin or integrity you do not trust.
Data warning: Creating a Tails USB erases the target USB drive. Make sure the correct drive is selected during preparation.

Official documentation

For the latest requirements and installation steps, use the official Tails installation guide. This guide is a companion, not a replacement for official instructions.

02 · First-time USB Setup

Use this checklist when you receive your Privacy USB for the first time. These steps assume the drive has already been prepared and tested by the seller.

Before plugging it in

  1. Read this guide first. Keep it open on this computer or, ideally, on a separate phone or computer while you start Tails.
  2. Save any open work on the computer you plan to use and close your applications.
  3. Check that you have the correct USB drive. This product has USB-A and USB-C connectors; use the connector that fits your computer without forcing it.
  4. If you need to protect important files, back them up before changing any computer settings. You normally do not need to change firmware settings just to try the boot menu.
Important: If this USB was supplied ready to use, do not run the Tails installer or repeat the USB creation process on this same drive. Creating or reinstalling Tails can erase the drive and its contents.

Start the first session

  1. Insert the prepared USB into the computer that you want to test.
  2. Restart the computer and open its one-time boot menu. The key varies by manufacturer; common examples are F12, F9, F11 or Esc.
  3. Select the USB device (choose the appropriate USB/UEFI entry if more than one is shown).
  4. When Tails starts, follow the on-screen Welcome Screen prompts. Continue to the Tor chapter in this guide for connection guidance.

Where should the guide live?

Keep a copy of this HTML guide on another device or in a browser before rebooting. A Tails USB does not automatically provide an ordinary, easily accessible place for extra guide files, and its partitions may not appear as expected in another operating system.

First test: Try the USB on a compatible spare computer before relying on it. Hardware, boot options and Wi-Fi support can vary.

03 · Boot from USB

  1. Insert the prepared Tails USB drive.
  2. Restart or power on the computer.
  3. Immediately press the computer's boot-menu key. Common keys include F12, F9, F11 or Esc, but the correct key depends on the manufacturer.
  4. Choose the USB device from the boot menu. If several entries appear, select the appropriate USB/UEFI entry for your computer.
  5. Follow the Tails startup and Welcome Screen prompts.
Do not guess. If you are unsure which device is the USB, stop and check the computer's manual. Avoid changing firmware settings unless necessary.

If the USB does not appear

  • Try another USB port.
  • Check the manufacturer's instructions for the boot-menu key.
  • Consult the official Tails troubleshooting page before changing Secure Boot or firmware settings.

04 · Connect to Tor

  1. When Tails starts, follow the Welcome Screen instructions.
  2. Connect to a supported network, such as Wi-Fi or Ethernet.
  3. Follow Tails' instructions for connecting to Tor. Network restrictions may require additional steps.
  4. Wait until the system indicates that the Tor connection is ready before browsing.
What Tor helps with: Tor is designed to make it harder for websites to link your connection to your ordinary IP address and to reduce some forms of network tracking.
What Tor does not do: It does not make every activity anonymous. Logging into personal accounts, sharing identifying details, downloading and opening files unsafely, or installing extra software can expose information.

05 · Protect Your Privacy

Everyday checklist

  • Separate identities: signing into a personal account can identify you even when using Tor.
  • Think before sharing: names, photos, locations, metadata and personal details can reveal who you are.
  • Keep the system current: follow official Tails update instructions.
  • Use trusted sources: install or download software only when necessary and from official sources.
  • Be cautious with files: documents and downloads can contain identifying content or create risks when opened outside the intended environment.
  • Shut down when finished: Tails is designed to minimise traces on the computer, but no system can guarantee that every trace is removed in every circumstance.

Remember

Privacy depends on your behaviour, your device, your network and your threat model—not just the operating system. Use the official documentation to understand the limitations that apply to your situation.

06 · Troubleshooting

The computer starts its usual operating system

Restart and open the boot menu again. Select the USB device rather than the internal drive. The boot-menu key differs by computer.

The USB is not listed

Try a different port, check the firmware's boot options, and consult the computer manufacturer's instructions. Do not change firmware settings blindly.

Tails starts but Wi-Fi is missing

Some wireless adapters are not supported. If possible, try Ethernet, then consult the official hardware and troubleshooting documentation.

The computer freezes or the screen stays blank

Compatibility varies. Check the official troubleshooting instructions for your exact symptom before trying startup options.
